# API Reference

> Generated by `/buddy:docs`. Routes are Next.js App Router handlers under `app/api/`; all run inside the Cloudflare Worker behind Cloudflare Access. The typed browser client is `app/lib/api-client.ts`.

## Conventions

- All endpoints are same-origin and JSON unless noted; request bodies are capped at **32 MB** (`next.config.ts`).
- In production every request must carry a valid Cloudflare Access JWT — the Worker rejects bypasses (`worker/access.ts`). Local dev disables the check via blank `CF_ACCESS_*` overrides in `.dev.vars`.
- Reference images go up as multipart files on the generation request; the browser budgets them under the 32 MB cap first (`app/lib/image-transport.ts`).

## References (`/api/references/*`)

Reference analysis and import. (The chunked `start`/`part`/`complete` upload routes were removed with Economy, their only client; generation takes references as multipart files.)

| Method | Path | Purpose |
|---|---|---|
| POST | `/api/references/analyze` | Vision analysis of a reference (`MATERIAL_COLLAGER_ANALYSIS_MODEL`) |
| POST | `/api/references/matches` | Material matching (`MATERIAL_COLLAGER_MATCH_MODEL`) |
| POST | `/api/references/import` | Import references from an exported draft |

### `/api/workbench/edit`: GPT Image 2.6 parameters

Multipart: a `payload` JSON field, plus `image[]` files, an optional `mask`,
and an optional `markup`. With no `image[]` files, the request goes to
`/v1/images/generations`; otherwise it goes to `/v1/images/edits`.

| Payload / file | Values | Rules |
|---|---|---|
| `complexity` | `low` \| `medium` \| `high` | Sent only when present. When omitted, the API default (`high`) applies. It has no fee of its own. Refused with 400 for the Test node's `gpt-image-2.5-sunburst-2026-09-08`. |
| `outputFormat` | `png` \| `jpeg` \| `webp` \| `svg` \| `gif` | `svg` and `gif` are generation-only, so they're refused when `image[]` is present. They're also refused for the 2.5 snapshot. `svg` forces `n=1`, and neither format sends `output_compression`. The response `mimeType` is `image/svg+xml` or `image/gif`. |
| `frameCount` / `frameDurationMs` | 2–64 / 20–2000 ms (rounded to 10) | GIF only. Out of range, or sent with any other format, returns 400. Size follows `validateGifSize`: multiples of 16 with no still-image pixel floor. Frames × pixels × n must fit the model's budget, and the API reports when they don't. |
| `markup` (file) | transparent PNG, ≤ 50 MB | An annotation layer over the FIRST `image[]`. It needs at least one input image and is never combined with `mask`. The Image Edit node checks in the browser that its size matches the input and that it has transparent pixels. The edge route can't do either check without decoding. |
| `image[]` | PNG, JPEG or WebP | SVG and GIF inputs are refused. |

Diagnostics record `complexity`, `frameCount`, `frameDurationMs` and
`markup: true` only when they were sent.

## Jobs

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/jobs` | The Generator's History drawer: the newest 30 generation jobs of every render kind, drafts included. Read-only; refreshes nothing and calls no model |
| GET | `/api/jobs/[id]/output` | Fetch a job's stored output while it is within retention |

## Example: dry-run a board

```bash
curl -X POST http://localhost:3000/api/dry-run \
  -H "Content-Type: application/json" \
  -d '{ "references": [], "layout": "master" }'
```

(Field shapes are defined by the route handlers and `app/lib/collage.ts`; consult `tests/collage-*.test.mjs` for canonical payload examples — the tests are the most reliable schema documentation in this repo.)

## Server-side environment

| Variable | Consumer | Purpose |
|---|---|---|
| `OPENAI_API_KEY` | `app/lib/openai-server.ts` | Image generation/edit |
| `MATERIAL_COLLAGER_ANALYSIS_MODEL` | `/api/references/analyze` | Override analysis model |
| `MATERIAL_COLLAGER_MATCH_MODEL` | `/api/references/matches` | Override match model |
| `CF_ACCESS_TEAM_DOMAIN`, `CF_ACCESS_AUD` | `worker/access.ts` | Access JWT verification (blank in local dev) |
| Bindings: `DB`, `OUTPUTS`, `IMAGES`, `ASSETS` | `worker/index.ts` | D1, R2, Images, static assets |
