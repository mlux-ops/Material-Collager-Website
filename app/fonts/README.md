# Inter webfonts

The production webfonts in this directory were converted from the project-supplied Inter 4.001 variable TTF files.

- `InterVariable.woff2`: normal variable font, `opsz` 14–32 and `wght` 100–900.
- `InterVariable-Italic.woff2`: italic variable font, `opsz` 14–32 and `wght` 100–900.

The conversion used fontTools 4.63.0 with Brotli WOFF2 output. Inter is distributed under the SIL Open Font License 1.1; see `LICENSE.txt`.
